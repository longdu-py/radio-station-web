# 📻 私人在线情感收音机
纯前端网页收音机，部署 GitHub Pages 免费在线访问，适合深夜伤感情歌、故事电台。

## 功能
1. 内置伤感情歌、怀旧老歌、深夜故事等多类电台
2. 支持自定义添加网络直播源(m3u8/mp3)
3. 音频动态频谱可视化背景
4. 电台收藏功能，本地存储不丢失
5. 定时自动关闭收音机
6. 音量调节、上/下一台快速切换
7. 深色治愈伤感电台UI，手机电脑自适应

## 使用方法
1. 打开网页，点击频道列表任意电台即可播放
2. 自定义电台：填入电台名称 + 直播源链接，点击添加
3. 喜欢的电台点击收藏，可切换标签只看收藏列表
4. 设置定时关闭，到点自动停止播放
5. 拖动滑块调节音量大小

## GitHub Pages 部署步骤
1. 新建GitHub仓库，上传全部4个文件
2. 仓库 Settings → Pages
3. Source 选择 Deploy from a branch
4. Branch: main，文件夹选择 /(root)，保存
5. 等待1分钟生成在线访问链接

## 技术栈
HTML5 / CSS3 / JavaScript
Web Audio API 音频频谱可视化
LocalStorage 本地存储收藏与自定义电台
原生 Audio 播放网络直播流
