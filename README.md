# 📻 深夜伤感情感收音机
纯前端网页电台，支持GitHub Pages免费部署，内置稳定央广m3u8直播源

## 功能清单
1. 内置7个稳定伤感/怀旧/治愈情感电台
2. 支持手动自定义添加任意m3u8/mp3网络电台流
3. 音频频谱动态可视化背景
4. 电台收藏功能，本地缓存永久保存
5. 定时自动关闭收音机（30/60/120分钟）
6. 音量滑块、上一台/下一台快速切换
7. 双标签：全部频道 / 我的收藏
8. 深色治愈伤感UI，手机电脑自适应

## 使用教程
1. 打开网站，直接点击左侧频道即可播放
2. 自定义电台：输入电台名称+m3u8直播链接，点击添加
3. 喜欢频道点击♥收藏，切换标签单独查看收藏列表
4. 设置定时，到点自动停止播放
5. 拖动滑块调节音量大小

## GitHub Pages部署步骤
1. 新建Github仓库，上传本项目4个文件
2. 仓库设置Settings → Pages
3. 部署来源：Deploy from a branch
4. 分支main，根目录/ (root)，保存
5. 等待1分钟生成在线访问网址

## 技术栈
HTML5 + CSS3 + JavaScript
Web Audio API 音频频谱可视化
LocalStorage 本地存储收藏、自定义电台
原生Audio标签播放HLS m3u8直播流
